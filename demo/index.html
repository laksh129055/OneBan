OneBan · live demo

Banned once. Blocked everywhere.

Three separate companies. One shared safety network. Ban someone for harassment on one platform, then watch him get stopped when he applies to the next.

🚕 QuickRide Ride-hailing · drivers 🔧 HomeFix Home services · technicians 🍱 FoodDash Food delivery · delivery partners

Run the demo in four steps

  1. QuickRide: register a driver. He is approved, because nobody has reported him.
  2. QuickRide: a rider's complaint is verified. Click Report & ban on that driver.
  3. HomeFix: the same man applies as a technician with the same phone number. The application is stopped.
  4. FoodDash: he tries again with a new SIM but the same ID number. Stopped again.

The network stores only a keyed hash of each phone and ID number. No platform sees another platform's data, and a match goes to a human reviewer rather than triggering an automatic ban.
